# H3-documentary

The repository contains the standalone app and its compatible pipeline in `pipeline/`.
Keep rendering, Italian local TTS, battle packs, generic historical documents and CLI formats compatible.
Never depend on a sibling checkout or user-specific absolute path. `data/` contains private jobs and settings; do not commit it.
Do not execute code generated by an LLM. Models provide validated data only.
Keys remain backend-only and must not be reused when the configured endpoint changes.
Keep all shared hard-linked geographic and voice input files immutable.
Use free dependencies; never upload audio externally or publish a video automatically.
Run targeted tests for settings, queueing, file access, installers and compiler changes.
Distinguish scripted fixtures from tests performed with a real configured LLM.
